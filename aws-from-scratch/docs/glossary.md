# AWS to Systems Engineering Glossary

This glossary maps AWS marketing terminology and acronyms directly to computer science, networking, and distributed systems primitives.

| AWS Service / Term | Underlying Primitive | What It Actually Is | Common Misconception |
|:---|:---|:---|:---|
| **VPC (Virtual Private Cloud)** | Software-Defined Network (SDN) / VXLAN Overlay | An isolated virtual network segment in AWS's software-defined hypervisor network mapping to a private RFC 1918 CIDR block. | "A physical data center or private wire." It is purely virtual packet encapsulation. |
| **Subnet** | IP Subnet within an AZ | A subdivided range of IP addresses within a VPC, physically confined to a single Availability Zone. | "Subnets span across the entire region." No: an AWS subnet is tied to exactly one AZ. |
| **Internet Gateway (IGW)** | 1-to-1 NAT & Default Route Target | A highly available software routing component performing 1-to-1 NAT between private VPC IPs and public IPv4 addresses. | "A physical router appliance that can get overwhelmed." It scales horizontally automatically. |
| **NAT Gateway** | Outbound Source NAT (SNAT) Proxy | A managed software proxy running in a public subnet allowing private instances to initiate outbound connections to the internet without accepting inbound. | "A free networking feature." It costs ~$0.045/hour + data processing per gateway. |
| **Security Group** | Stateful Distributed Packet Filter | A hypervisor-level virtual firewall applied to virtual network interfaces (ENIs). Automatically allows return traffic. | "A subnet-level firewall." SGs are applied at the network interface level, not the subnet level. |
| **Network ACL (NACL)** | Stateless Subnet Packet Filter | A subnet boundary packet filter evaluated in numbered rule order. Return traffic must be explicitly permitted in ephemeral port ranges. | "The primary way to secure EC2 instances." SGs should be your primary firewall; NACLs are a coarse boundary. |
| **EC2 (Elastic Compute Cloud)** | Virtual Machine (KVM/Nitro VM) | A virtualized machine running on a physical host managed by AWS Nitro hypervisor cards. | "A physical server in a rack." It shares hardware unless Dedicated Hosts are purchased. |
| **AMI (Amazon Machine Image)** | Bootable OS Disk Snapshot & Metadata | A pre-packaged root filesystem snapshot (EBS or instance-store) combined with kernel and block device mappings. | "A Docker container." An AMI boots a full OS kernel and virtualized hardware. |
| **EBS (Elastic Block Store)** | Network-Attached Storage (SAN / iSCSI volume) | A persistent block device attached over a dedicated local network link to a virtual machine hypervisor. | "A local hard drive in the physical server chassis." It is network-attached and isolated per AZ. |
| **S3 (Simple Storage Service)** | Distributed HTTP Object Store | A distributed, partition-tolerant key-value store optimized for large, immutable byte streams accessed via HTTP REST APIs. | "A POSIX filesystem with folders and file handles." There are no real directories—only keys with `/` delimiters. |
| **ALB (Application Load Balancer)** | Reverse HTTP/HTTPS Proxy (Envoy/Nginx style) | A managed Layer 7 reverse proxy parsing HTTP/1.1, HTTP/2, and gRPC headers to route requests to backend target groups. | "A Layer 4 packet router." That is NLB (Network Load Balancer). ALB terminates HTTP connections. |
| **Auto Scaling Group (ASG)** | Process Supervisor & Capacity Controller | An automated controller loop that monitors fleet metrics and invokes EC2 launch/terminate APIs to maintain target capacity. | "Instant elasticity." EC2 boot times (2-5 mins) mean ASGs react with lag compared to container pools. |
| **RDS (Relational Database Service)** | Managed PostgreSQL/MySQL/MariaDB on EC2 | An EC2 instance running a standard relational database engine with automated EBS snapshots, OS patching, and managed failover. | "A proprietary database engine." It runs standard open-source engines with managed operations. |
| **DynamoDB** | Distributed Hash-Partitioned Key-Value Store | A horizontally scalable, distributed B-tree/LSM-tree storage system with automatic sharding based on partition keys. | "A drop-in MongoDB replacement." Modeling requires strict upfront knowledge of query access patterns. |
| **ElastiCache** | Managed Redis / Valkey / Memcached In-Memory Cluster | An in-memory key-value data store cluster running on managed compute nodes with automated replication and cluster routing. | "A persistent primary database." In-memory stores are primarily for cache buffering or transient state. |
| **SQS (Simple Queue Service)** | Distributed At-Least-Once Buffer | A horizontally partitioned FIFO/Standard message buffer where messages are stored redundantly across multiple storage nodes. | "A pub/sub broadcast system." SQS is point-to-point competing consumers. For broadcast, use SNS. |
| **SNS (Simple Notification Service)** | Publish/Subscribe Broadcast Fan-Out | An asynchronous pub/sub messaging hub pushing messages to multiple heterogeneous subscribers (SQS, email, HTTP, Lambda). | "A message queue that holds messages." SNS pushes immediately; if a subscriber is unreachable, messages may drop. |
| **EventBridge** | Enterprise Event Bus & Content Router | A declarative JSON message router evaluating rule patterns to filter, transform, and dispatch events to dozens of targets. | "Just SNS with a new name." EventBridge includes schema registries, JSON path matching, and SaaS ingestion. |
| **Lambda** | Ephemeral Micro-VM Execution (Firecracker) | Event-driven compute that spins up micro-VM containers (using Firecracker) on demand to execute single function invocations. | "Serverless means no servers." There are servers; AWS manages their provisioning, scaling, and lifecycle. |
| **ECS (Elastic Container Service)** | Container Orchestration Control Plane | AWS-native task scheduler that coordinates Docker container lifecycles across EC2 fleets or Fargate serverless capacity. | "A simplified Kubernetes." It has a fundamentally simpler data model (Task Definitions, Tasks, Services). |
| **Fargate** | Serverless Container Capacity Provider | A managed execution environment that runs container tasks without provisioning or managing underlying EC2 virtual machines. | "A container runtime." It is a compute engine abstracting VM management for ECS or EKS. |
| **CloudWatch** | Time-Series Metrics & Log Aggregator | A centralized telemetry platform collecting numerical metrics (1-minute or 1-second resolution), structured logs, and threshold alarms. | "Real-time instant profiling." Metrics usually arrive with 1 to 5 minutes of reporting delay. |
| **IAM (Identity & Access Management)** | Policy-Based Authorization (ABAC/RBAC) Engine | A declarative policy evaluation engine assessing Principal, Action, Resource, and Context conditions on every API call. | "Simple username/password login." IAM is primarily about machine-to-machine cryptographic authorization. |
| **KMS (Key Management Service)** | Hardware Security Module (HSM) Key Wrapper | A cluster of FIPS 140-2 validated HSMs generating and managing master keys to perform envelope encryption. | "A service where AWS sees your plaintext keys." Customer master keys never leave the HSM unencrypted. |
| **CloudFront** | Global Anycast Reverse Proxy / Edge Cache | A worldwide network of Point of Presence (PoP) edge servers caching static content and proxying dynamic requests via AWS backbone. | "Just an image storage service." It handles TLS termination, DDoS mitigation, and HTTP edge computing. |
| **Route 53** | Distributed Anycast Authoritative DNS Server | A globally distributed authoritative DNS service offering latency-based, geolocation, failover, and weighted record routing. | "A domain registrar only." Registration is a secondary feature; its primary function is authoritative DNS resolution. |
