# Solution: Broken Pipeline Lab 08 — Circular Dependency in Build Graph Halts Pipeline

## 1. Root Cause Analysis
Target A depended on Target B's generated code, while Target B imported headers generated by Target A.

---

## 2. Step-by-Step Fix
Refactor shared types or schemas into an independent Target C upon which both A and B depend.

---

## 3. Verification Command
To verify that the fix resolves the issue, run:
```bash
python3 broken-pipelines/08-build-dag-circular-dependency/solution/verify_fix.py
```
