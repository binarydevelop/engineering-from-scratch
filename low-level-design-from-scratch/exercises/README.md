# Low-Level Design Exercises & Practice Drills

This directory contains **155 structured LLD exercises** across 6 core competency areas, designed to transform passive theoretical understanding into active design mastery.

## Categorized Breakdown

| Category | Exercise Count | Prefix | Focus |
|:---|:---|:---|:---|
| **01-requirement-analysis** | 30 exercises | `req-01` to `req-30` | Decomposing vague real-world prompts, handling ambiguity, and defining boundaries before writing code. |
| **02-domain-modeling** | 30 exercises | `model-01` to `model-30` | Extracting entities, value objects, aggregates, and data structures from domain descriptions. |
| **03-solid-and-refactoring** | 25 exercises | `solid-01` to `solid-25` | Diagnosing code smells, identifying change vectors, and applying SOLID heuristics to refactor fragile code. |
| **04-design-patterns** | 25 exercises | `pattern-01` to `pattern-25` | Pain-driven application of Strategy, Observer, Builder, Adapter, State, Decorator, and Command. |
| **05-testing-and-testability** | 20 exercises | `test-01` to `test-20` | Writing characterization tests, hand-rolling test doubles, and eliminating static/clock dependencies. |
| **06-full-design-problems** | 25 exercises | `problem-01` to `problem-25` | End-to-end LLD interview problems with complete requirement decomposition, models, and contracts. |

**Total Exercises:** 155  
**Total Reference Solutions:** 155 (located in `exercises/solutions/`)

---

## Pedagogical Practice Rule

> ⚠️ **Do NOT look at `exercises/solutions/` before attempting the problem yourself!**  
> Spend at least 30 minutes tracing use cases, writing the responsibility table, and defining invariants. Compare your design against the reference solution only after completing your own model.
