# Design Kata: Dynamic Strategy Dispatch

**Goal:** Practice repeatable, high-speed refactoring mechanics.

---

## The Challenge
Refactor a hardcoded pricing algorithm into an interchangeable Strategy pattern allowing runtime tariff swapping.

---

## Instructions
1. Open a blank editor without referencing external templates.
2. Implement the problem with naive procedural code.
3. Identify where the code resists change when a new requirement is introduced.
4. Refactor in under 15 minutes to clean, test-covered object-oriented design.
5. Re-run repeatedly until the mental model is second nature.
