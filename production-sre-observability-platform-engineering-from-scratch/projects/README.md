# Substantial Engineering Projects (Projects 01 – 12)

> **Motto**: You do not truly understand an architecture until you have built it from scratch.

---

## Overview

The 12 projects in this section bridge the gap between isolated lessons and full production platforms. Each project delivers a substantial, runnable tool, pipeline, platform capability, or framework:

```text
Observability Projects (Projects 01 – 03)
   ├── Project 01: Instrument a Backend Service from Scratch (OTel SDK, RED Metrics, Logs)
   ├── Project 02: Production OTel Collector Pipeline (Memory Limiter, Batch, Exporters)
   └── Project 03: Production Observability Dashboard Suite (Grafana RED/USE/Signals)

Reliability & SRE Projects (Projects 04 – 07)
   ├── Project 04: SLO Platform Lite (Error Budget Engine & Burn Rate Alerts)
   ├── Project 05: Production Alerting System (Prometheus Rules & Alertmanager Routing)
   ├── Project 06: Interactive Incident Simulator (Chaos Dispatcher & Timeline Builder)
   └── Project 07: Production Capacity Planner (Traffic Modeling & Headroom Analyzer)

Platform Engineering Projects (Projects 08 – 12)
   ├── Project 08: Production Readiness Review (PRR) CLI & Linter
   ├── Project 09: Service Bootstrap Platform (`platform new-service`)
   ├── Project 10: Internal Developer Platform Lite (Declarative `service.yaml`)
   ├── Project 11: Microservice Software Catalog (Metadata, Dependencies, SLO Links)
   └── Project 12: End-to-End Golden Path (Zero to Observable Deployed Service)
```

Each project contains its own specification, starter code, implementation, tests, and verification guide.
