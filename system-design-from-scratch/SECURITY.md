# Security Policy

## 1. Supported Versions

| Version | Supported |
| :--- | :--- |
| `1.x` (Current Main) | :white_check_mark: |
| `< 1.0` | :x: |

---

## 2. Reporting a Vulnerability

If you discover a security vulnerability within this repository or its simulation harnesses:
- Please **do not** open a public issue.
- Email security findings privately to `security@example.com`.
- We will acknowledge receipt within 48 hours and coordinate a coordinated disclosure.

---

## 3. Educational Security Boundaries

The simulation models in this repository (e.g. rate limiters, token parsers, hash rings) are intended for educational demonstration and performance analysis. Production deployments should always employ hardened, battle-tested implementations and defense-in-depth security practices.
